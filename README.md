# dj1203labs.com

The DJ1203 Labs website, served by GitHub Pages from this repository's `main` branch.

- `index.html`: the home page (Intuimix, pricing, beta, what's next)
- `beta.html`: the beta download page; its buttons point at the newest signed installers on github.com/dj1203productions-stack/intuimix-releases (fixed file names, so they never need changing)
- `assets/`: the Intuimix logo and the browser icon
- `CNAME`: tells GitHub Pages to answer for dj1203labs.com
